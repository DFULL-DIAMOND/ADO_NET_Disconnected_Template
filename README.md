# Шаблон: ADO.NET Disconnected Mode (Отсоединенный режим)

Этот репозиторий — базовый шаблон для WinForms-приложений, использующих **отсоединенный режим** работы с данными (`SqlDataAdapter` + `DataTable`).

## 🏗 Архитектура
*   **UI (WinForms)**: Только `Form1` (окно подключения `ClosedForm` намеренно убрано, так как оно не нужно для этого режима).
*   **Data**: `ConnectionFactory` (строка подключения), `QueryDefinition` и **`DataAdapterRunner`** (выполняет запросы через `SqlDataAdapter`).
*   **Queries**: `QueryRegistry` (словарь SQL-запросов).
*   **Особенность**: Соединение с БД открывается ровно на ту миллисекунду, пока `SqlDataAdapter` выгружает данные в память (`DataTable`), и сразу закрывается.

## 🚀 Как начать новый проект на базе этого шаблона:
1. Нажмите **"Use this template"** на GitHub (или склонируйте репозиторий).
2. Откройте решение в Visual Studio.
3. В файле `Data/ConnectionFactory.cs` измените `InitialCatalog` на имя вашей базы данных.
4. В `Queries/QueryRegistry.cs` добавьте свои SQL-запросы (поддерживаются параметры через `@name`).
5. В `Form1.cs` обновите пункты выпадающего списка (`ComboBox`), чтобы они соответствовали вашим запросам.

## 💡 В чем магия этого режима?
*   **Нет утечек памяти и "зомби-процессов".** Программа закрывается мгновенно, потому что нет открытого соединения.
*   **Простота кода.** Вам не нужно вручную создавать колонки в `DataGridView`. Вы просто передаете `DataTable` через `DataSource`, и WinForms сам всё рисует.
*   **Минимальная нагрузка на сеть.** Вы делаете один запрос и забираете сразу всю таблицу в оперативную память.

## ⚠️ Важно помнить:
*   Если таблица в базе огромная (сотни тысяч строк), `DataTable` съест много оперативной памяти. Для обычных учебных и бизнес-задач (до 10-50 тысяч строк) это лучший выбор.
